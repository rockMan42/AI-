# 证据判断改进及复测

## 实现

- Rerank下限0.15；0.4仅作为相关性观测分段。两段均通过一次LLM判断证据并生成回答。
- 内部结果为answerable、answer、evidence原文数组；程序在本次MySQL已授权且有效的候选正文中逐字定位来源，只返回实际引用。外部响应结构不变。
- 不再让模型生成来源ID，避免与条款编号混淆；按原文行提供资料，避免跨行拼接和转义错误。不做模糊匹配，不忽略错误证据。
- 无法回答走固定兜底；JSON错误、伪造证据、缺少证据、截断仍为错误。预算5秒、输出512，返回前提交加密日志。

## 过程与限制

- r1和r2各4个业务错误：引用编号混淆等；r3剩余A41跨行证据拼接错误。所有失败记录原样保留，不纳入r4成功数。
- 仓库外执行7项证据结构、不存在原文、拒答矛盾及截断的手工检查；未新增仓库测试代码。
- 0.15是在原100题上探索的实验值，没有独立人工标注集；本轮回归结果不等于对任意问题的质量保证。逐字证据匹配不能证明所有回答结论被证据支持。
- 原始制度歧义未自动修订。知识数据快照未改变，正常产生加密日志和查询向量缓存。
- 已有常驻API/MCP进程需重启加载；本轮新启动的调用方及MCP子进程已使用修改。
